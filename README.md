# AURAK Finals Schedule Maker

Pick your courses and sections, get your final exam timetable as an image or calendar file.

- Exam data: AURAK's published final exam schedule (Google Sheets), fetched live, with a built-in copy as fallback.
- Course titles: AURAK catalogs 2023–2027.
- Single static page: `index.html`, no build step.

Made with the AURAK Student Government Association theme.
